# OracleRegistry – Trusted Data Oracle Directory

OracleRegistry enables decentralized applications to verify and reference trusted oracle providers for accurate off-chain data delivery.

## Core Capabilities
- Register and manage authorized oracle providers
- Assign oracle feeds to specific data types
- Enable/disable oracle status for security response
- Public verification of oracle trust level

## Key Functions
register-oracle, set-feed, disable-oracle, get-oracle, get-feed
